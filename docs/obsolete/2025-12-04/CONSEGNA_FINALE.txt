🎯 INTEGRAZIONE IN ALTRI MODULI

Il sistema è PLUG-AND-PLAY! Per usarlo in qualsiasi entità:

import ImportButton from '../Platform/ImportButton';

<ImportButton
  moduleName="affitti_lungo"           // Nome modulo
  entityName="Contratto"                // Nome entità
  entityLabel="Contratti"               // Label visualizzata
  onImportComplete={() => refreshData()}
/>

Requisiti entità:
✓ Model SQLAlchemy in app/modules/{module}/models/{entity}.py
✓ Schema {Entity}Create in app/modules/{module}/schemas/

Nessun'altra configurazione necessaria!
