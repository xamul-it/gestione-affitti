CRITICAL ISSUE IDENTIFIED
================================================================================

DEFECT-001: SQLAlchemy Cross-Module Relationship Initialization Failure

Issue:
  Backend fails during startup when attempting to configure model relationships
  across modules. SQLAlchemy tries to validate relationships before all related
  model classes have been imported.

Error:
  sqlalchemy.exc.InvalidRequestError: One or more mappers failed to initialize
  - Mapper 'Mapper[SoggettoAnagrafico]' has no property 'affittuari'

Root Cause:
  Modular refactoring split models across 3 modules:
  - anagrafica_italiana (SoggettoAnagrafico model)
  - immobili (Proprietario model)
  - affitti_lungo (Affittuario, Tecnico models)
  
  Child models define back_populates relationships to SoggettoAnagrafico, but
  parent model doesn't define reverse relationships when mapper initialization
  occurs. This is a TIMING PROBLEM with import order and SQLAlchemy configuration.

Platform Impact:
  - Backend API completely unavailable
  - Cannot test ANY functionality
  - No authentication, no dashboard, no modules, no navigation
  - 42 planned test steps BLOCKED
